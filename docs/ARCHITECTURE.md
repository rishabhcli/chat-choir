# Architecture

## Data flow

Twitch Device Code OAuth (`src/twitch/auth.js`) obtains a public-client user token, validates it and rotates refresh tokens. `helix.js` wraps users, replies and EventSub subscriptions with 401 refresh and 429 backoff. `eventsub.js` manages WebSocket welcome, keepalive, handoff, deduplication, revocations and retries; `normalize.js` converts Twitch payloads to application events. Tests use hand-written fixtures and local fake services.

`src/server/policy.js` filters chat and rate-limits users. `src/server/index.js` binds localhost, applies commands and moderation, appends accepted entries to a JSONL session, and broadcasts a hello containing the complete log followed by live events. Local HTTP endpoints expose settings, test messages and exports. A reconnecting or late client gets the same history. Replay feeds the same server using timestamps from a recording, without Twitch.

`src/music/session.js` is the shared log reducer. Node and browser independently apply chat, settings, removal and celebration entries to the same `Transport`; the transport uses explicit timestamps and emits absolute-time events. Settings take effect on the next bar. Mutations must be chronological. Event windows are half-open `[start,end)` and queries do not advance a clock. The snapshot supplies current chord and active lyric/note information.

`theory.js` defines scales, chords and quantization, `phrase.js` maps text to bounded melodies and percussion, `commands.js` handles timestamped votes, and `midi.js` exports format-1 MIDI and lyrics. `src/synth/dsp.js` and the nine plugins in `instruments/` contain the one sample-buffer synthesizer. `src/cli/preview.js` auditions any plugin with a D dorian phrase. The generated static registry makes all discovered plugins importable in browsers. The offline mixer pans, sums, reverberates and soft-limits; browser playback caches those same sample buffers, schedules them with lookahead, and uses Web Audio only for routing, panning, gain and compression. The browser does not implement a second synth.

`public/view-model.js` contains pure layout and word-placement helpers. `overlay.js` draws the canvas and `dashboard.js` manages controls. `src/cli/render.js` replays JSON or JSONL to a normalized WAV; `src/cli/replay.js` runs the server with a timed recording. `public/manual-clock.js` reconstructs a log prefix for any explicit timestamp and derives animation state from recorded event times. `scripts/capture.mjs` seeks it with Playwright to write transparent PNG frames; `scripts/smoke-overlay.mjs` exercises live audio and inspects reproducibility in headless Chromium.

## Determinism and boundaries

Music decisions and instrument samples use only explicit inputs and seeded hashes/noise, never wall-clock time, network data, timers or `Math.random`. The server converts arrival time into an explicit session timestamp before logging. Equal ordered logs, settings, implementation and sample rate produce identical arrangements and instrument buffers on the same runtime; transcendental floating-point behavior can differ by engine or hardware. Network latency, client audio devices, browser compression and offline mastering can change perceived playback. Melodic assignment uses rendezvous scores with a compatibility group that preserves the original five-voice modulo mapping; adding a plugin changes only users assigned to the new plugin. Removing a plugin can reassign users.

Live OAuth and EventSub necessarily use network and timers, but those do not generate musical randomness. Tokens, seen-user state, and logs are local; do not print them. No framework, paid service, bundled copyrighted audio, or build step is required.

WAV sample zero and capture frame zero use the first recorded event timestamp; capture's `--from` and `--to` are relative to that origin, while `__choir.seek(ms)` uses absolute session milliseconds. An opening chat event exactly at timestamp zero starts at the initial downbeat. Existing rests are not silently removed. Fixed browser, fonts and viewport are needed for identical raster pixels. The browser analyser measures post-compressor master output without affecting the audio path.
