# Chat Choir project conventions

Chat Choir is an offline-first Twitch chat-to-music instrument. Use ES modules, plain JavaScript with JSDoc where useful, Node built-ins, `ws`, and `node --test`. Avoid frameworks, bundlers, paid APIs, copyrighted audio, and sample assets. Keep runtime dependencies minimal. Do not inspect or print real `.env`, `.data/`, or token files.

Commands: `npm install`, `npm test`, `npm run login`, `npm start`, `npm run replay -- samples/demo-session.json`, `npm run render -- samples/demo-session.json /tmp/demo.wav`, `npm run smoke`, and `npm run capture -- session.jsonl /tmp/frames --fps 30`. If Node is not on PATH, prefix commands with `PATH=/opt/homebrew/bin:$PATH`. Use temporary directories and fake tokens for tests; no live Twitch credentials are needed. Configure voting with `CHOIR_VOTES` (integer 1–20, default 3) and `CHOIR_VOTE_WINDOW_SECONDS` (positive seconds, default 60); ignore the authenticated bot user ID on chat intake.

Architecture: `src/music/theory.js` handles scales and chords; `phrase.js` converts messages; `transport.js` schedules explicit-time events; `session.js` is the shared session-log reducer; `commands.js` handles votes; `midi.js` exports MIDI and lyrics. `src/synth/dsp.js`, `instruments/`, `registry.js`, and `mixer.js` implement the single shared browser/Node synth. `src/twitch/` contains public device OAuth, Helix, EventSub and normalization. `src/server/` owns localhost HTTP/WebSocket, policy, and append-only logs. `src/cli/` renders and replays. `public/` is the plain browser overlay and dashboard; keep view calculations testable in `view-model.js`. `public/manual-clock.js` reconstructs session state for frame-exact capture, and `scripts/` contains the separate Playwright smoke and PNG capture tools. `__choir.seek(ms)` uses absolute event timestamps; capture frame zero and WAV sample zero both start at the first recorded event. See `docs/ARCHITECTURE.md`.

All musical decisions and synthesis must be pure and deterministic for identical inputs. Never use `Math.random`, timers, wall-clock time, network data, or audio assets to decide notes or samples. Pass session timestamps explicitly and use the seeded DSP noise helper. Keep browser-shared modules free of Node-only imports. EventSub I/O, clocks, and browser scheduling are necessarily asynchronous and must stay outside the pure engine.

Instrument recipe: add one file in `src/synth/instruments/` exporting `id`, `name`, `role`, and `render(note, sampleRate)`. Return a deterministic, non-silent Float32Array with finite samples, peak <= 1, and a near-silent tail. Use `melodic` role for ordinary voice selection. Run `npm test` to regenerate the browser-compatible static registry and exercise automatic conformance; commit `registry.generated.js`. Test changes alongside modules, verify the demo render, run the headless smoke test for browser changes, inspect its screenshots, and make small, logical commits.
